# SongData / Music

These are one-shot stage announcements, not the level's background soundtrack.

| File | Trigger |
|---|---|
| `awesome.ogg` | Once per run, when the player reaches 30 seconds in the level |
| `excellent.ogg` | Once per run, when the player reaches 60 seconds in the level |
| `wonderful.ogg` | When the run establishes a new personal best |

Use these exact lowercase filenames. OGG files are optional while developing; missing files are skipped without interrupting gameplay.

The existing level soundtrack files and beat charts remain in `MusicData/`.
