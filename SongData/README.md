# SongData

Optional OGG cues live here:

- `Music/`: the 30-second / 60-second voice announcements and new-record callout
- `Sounds/`: game start/death voice, menu effects and the synchronized `rankup.ogg` backing layer

The actual level songs and any explicitly authored beat-chart JSON files stay in the existing `MusicData/` folder. Paths decide per level whether to use an authored chart or beat-sensitive generation.
